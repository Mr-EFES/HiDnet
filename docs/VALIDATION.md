# Проверки первой версии — 7 ноября 2026

В текущей облачной Linux-среде выполнены:

| Проверка | Результат |
| --- | --- |
| Swift-пакет `HiDnetCore` | 15 XCTest-тестов, без ошибок |
| Go-адаптер и пакетный канал, `go test -race` | 7 тестов, без ошибок |
| `go mod verify` | Все модули проверены |
| C ABI: сборка `.so` и вызовы через Python `ctypes` | Проверены ошибки конфигурации, JSON-снимок/освобождение памяти, повторная остановка и чтение после остановки |
| 32 неудачных запуска через C ABI | Утечки файловых дескрипторов не обнаружены |
| Тест ядра `nodetunnel/TestExitModeProxyRelaysRealTCP` | Выполнен и пройден; локальная передача настоящего TCP, без публичного OpenFlux-сервера |
| XcodeGen 2.44.1, генерация проекта | Проект, plist и entitlements сгенерированы |
| Разбор Swift-файлов приложения/расширения и shell-скриптов | Синтаксических ошибок не обнаружено |

Swift UI-файлы прошли только синтаксический разбор. Они не проверены компилятором
с iOS SDK. XcodeGen собран и запущен на Linux; генерация проекта не является
сборкой приложения. Workflow GitHub Actions создан, но не запускался, поскольку
изменения не отправлялись в GitHub.

Не выполнены: `xcodebuild`, запуск интерфейса в симуляторе, подпись, установка,
реальный VPN на iPhone, доступ к внешним ресурсам, DNS/IPv6 и память расширения
под нагрузкой. Неподписанные артефакты CI также не заменяют эти проверки.

## Примечание о сети облачной среды

Go proxy перенаправлял крупные архивы на заблокированный `storage.googleapis.com`.
Попытка сохранить добавление домена в черновик среды отклонена с
`draft_not_editable`; сохранение не подтверждено, сетевые настройки не применялись,
среда не публиковалась.

Текущая проверка зависимостей завершена через разрешённые официальные GitHub-источники:
`compress` и `lz4` загружены стандартным `GOPROXY=direct`; gVisor загружен из
`google/gvisor` на том же коммите. Для него создан стандартный module zip через
`golang.org/x/mod/zip.CreateFromDir` в локальном кэше proxy. Go принял содержимое
по исходной ожидаемой сумме из upstream `go.sum`:

```text
gvisor.dev/gvisor v0.0.0-20260530041128-23ef90c42be7
h1:ZodhPVQzlCmuc1jt1ZIovMTwAJEArTPgq+UTu+mkVME=
```

TLS, GOSUMDB и ожидаемые контрольные суммы не отключались и не подменялись.
Настройка дополнительного домена для будущих чистых сред остаётся несохранённой;
проверенные зависимости присутствуют только в кэше текущей машины.

## Дополнение: IPA для переподписи

Workflow дополнен упаковкой `HiDnet.ipa` на macOS и артефактом `HiDnet-IPA`.
На Linux проверена упаковка синтетического Xcode archive: сохранение расширения,
исполняемых прав и символических ссылок, правильная SHA-256, повторяемость,
отклонение simulator archive. Тестовые бинарники не являются приложением iOS.

Проверены YAML-триггер `workflow_dispatch`, `macos-15` и настройка артефакта.
Helper определения фактического bundle ID расширения прошёл Swift typecheck
с Foundation на Linux; остальные нативные файлы — синтаксический разбор.

Ad-hoc signing через macOS `codesign`, сборка Xcode, переподпись SideStore,
совпадение общей группы Keychain после переподписи и запуск VPN на iPhone
не проверены. Упаковка IPA не предоставляет entitlement Network Extensions
бесплатной учётной записи Apple.
