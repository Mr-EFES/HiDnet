## Примечание о сети облачной среды

Go proxy перенаправлял крупные архивы на заблокированный `storage.googleapis.com`.
Попытка сохранить добавление домена в черновик среды отклонена с
`draft_not_editable`; сохранение не подтверждено, сетевые настройки не применялись,
среда не публиковалась.

Текущая проверка зависимостей завершена через разрешённые официальные GitHub-источники:
`compress` и `lz4` загружены стандартным `GOPROXY=direct`; gVisor загружен из
`google/gvisor` на том же коммите. Для него создан стандартный module zip через
`golang.org/x/mod/zip.CreateFromDir` в локальном кэше proxy. Go принял содержимое
по исходной ожидаемой сумме из upstream `go.sum`:

```text
gvisor.dev/gvisor v0.0.0-20260530041128-23ef90c42be7
h1:ZodhPVQzlCmuc1jt1ZIovMTwAJEArTPgq+UTu+mkVME=
```

TLS, GOSUMDB и ожидаемые контрольные суммы не отключались и не подменялись.
Настройка дополнительного домена для будущих чистых сред остаётся несохранённой;
проверенные зависимости присутствуют только в кэше текущей машины.

## Дополнение: IPA для переподписи

Workflow дополнен упаковкой `HiDnet.ipa` на macOS и артефактом `HiDnet-IPA`.
На Linux проверена упаковка синтетического Xcode archive: сохранение расширения,
исполняемых прав и символических ссылок, правильная SHA-256, повторяемость,
отклонение simulator archive. Тестовые бинарники не являются приложением iOS.

Проверены YAML-триггер `workflow_dispatch`, `macos-15` и настройка артефакта.
Helper определения фактического bundle ID расширения прошёл Swift typecheck
с Foundation на Linux; остальные нативные файлы — синтаксический разбор.

Переподпись SideStore, совпадение общей группы Keychain после переподписи и
запуск VPN на iPhone не проверены. Упаковка IPA не предоставляет entitlement
Network Extensions бесплатной учётной записи Apple.

## Первая macOS-сборка

[GitHub Actions #42392315098](https://github.com/Mr-EFES/HiDnet/actions/runs/42392315098)
для commit `4527376d6910f07c45f443dfefaf8364f7bf858b` завершилась успешно.
Общая длительность: 4 минуты 39 секунд. В задаче `build` выполнены:

- тесты Swift и Go с проверкой модулей;
- сборка Go C archive для iPhone arm64 и симуляторов arm64/x86_64;
- создание XCFramework и проекта Xcode;
- `xcodebuild archive` приложения и расширения для iPhone;
- упаковка IPA, ad-hoc `codesign` и `codesign --verify --deep --strict`;
- упаковка соответствующих исходников;
- `xcodebuild build` для iOS Simulator.

Архив соответствующих исходников также проверен локально: из него выполнены
все 7 Go-тестов с `-race -mod=vendor`, `GOPROXY=off` и пустым module cache.
Бинарники первой сборки ветки не публиковались. Релизная сборка выполнена отдельно
после перехода на согласованную владельцем GPLv3.
